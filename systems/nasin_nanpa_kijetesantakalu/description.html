nasin nanpa kijetesantakalu is a joke number system that was featured in the Toki Pona Dictionary. It consists of the word kijetesantakalu with a different stressed syllable each time to represent a digit in base 6. The stress is not marked in writing, making all digits indistinguishable.

This site's conversion tools allows writing a syllable in uppercase to denote stress, for example "kijeteSANtakalu" is 3.
